# ИИ-ассистент поддержки для WhatsApp

Бот отвечает клиентам, которые пишут вашему бизнесу в WhatsApp. Два режима: **обычный WhatsApp по QR-коду** (просто, но неофициально, с риском блокировки номера) и **официальный WhatsApp Business Platform** через партнёра Meta (BSP). Ответы пишет Claude по вашей базе знаний. Сотрудники видят все диалоги в панели оператора и перехватывают разговор в один клик.

## Программа для Windows (самый простой способ)

Запустите установщик `WhatsApp-AI-Assistant-Setup-1.0.0.exe`: он за пару секунд поставит программу (без прав администратора) и создаст ярлык «ИИ-ассистент WhatsApp» на рабочем столе. Node.js и терминал не нужны.

1. При первом запуске Windows может показать «Система Windows защитила ваш компьютер» (программа без цифровой подписи). Нажмите «Подробнее» → «Выполнить в любом случае».
2. Прочитайте предупреждение о рисках и нажмите «Понимаю, продолжить».
3. В окне программы отсканируйте QR-код телефоном: WhatsApp → Настройки → Связанные устройства → Привязка устройства.
4. Выберите ИИ, вставьте ключ, нажмите «Сохранить».
5. Нажмите «Открыть редактор» в разделе «База знаний» и опишите свою компанию, имя ассистента и ответы на частые вопросы.

Пока программа открыта (можно свернуть), бот отвечает клиентам. Если закрыть, бот перестанет отвечать. Настройки, вход в WhatsApp и переписка хранятся в `%APPDATA%\WhatsApp AI Assistant`.

Собрать установщик самому (на Windows): `npm install`, затем `npm run build:win` (файл появится в папке `dist`). На Linux для сборки установщика нужен wine. Запустить окно без сборки: `npm run desktop`.

## Быстрый старт: обычный WhatsApp по QR-коду

Самый простой режим: ни партнёра, ни ngrok, ни сервера не нужно. Бот подключается к вашему номеру как WhatsApp Web на компьютере.

> ⚠️ **Риск блокировки номера.** Этот режим неофициальный (библиотека Baileys) и нарушает условия использования WhatsApp. WhatsApp может заблокировать номер, иногда навсегда, вместе с историей чатов. Используйте номер, потерю которого вы готовы пережить. Для надёжной работы переходите на официальный API (разделы ниже), код бота тот же.

Что заложено в этом режиме:
- бот отвечает **только в личных чатах, где клиент написал первым**; группы, статусы и каналы игнорируются;
- **никаких рассылок** и сообщений первым: даже оператор из панели может писать только тем, кто уже писал вам;
- **лимит ответов бота в день для каждого номера** (по умолчанию 100, меняется в панели). Когда лимит исчерпан, бот молчит до полуночи, а чаты помечаются для оператора;
- сообщения, пришедшие пока бот был выключен (старше 10 минут), бот не трогает: на них отвечает оператор;
- если подключено несколько номеров, **они никогда не переписываются друг с другом**: сообщения между номерами бота игнорируются, отправить их тоже нельзя.

Запуск:

1. Установите Node.js 22.13 или новее (nodejs.org).
2. В папке бота выполните:
   ```bash
   npm install
   cp .env.example .env
   ```
   В `.env` задайте `ADMIN_PASSWORD` (`WA_PROVIDER=web` уже стоит по умолчанию).
3. `npm start`
4. Откройте http://localhost:3000/admin (логин `admin`, пароль из `.env`).
5. На телефоне: WhatsApp → Настройки → Связанные устройства → Привязка устройства, отсканируйте QR-код из панели.
6. В панели выберите ИИ (можно бесплатный, см. «Какой ИИ выбрать»), вставьте ключ и при необходимости поменяйте лимит, нажмите «Сохранить».

### Несколько номеров

В панели нажмите «+ Добавить номер», дайте ему название и отсканируйте его QR-код телефоном этого номера. У каждого номера:
- своя сессия и свой QR-код (выйти или удалить номер можно кнопками в его карточке);
- свой дневной лимит ответов бота;
- общая база знаний из `knowledge/*.md` плюс своя: файлы в `knowledge/<id номера>/` (id показан в карточке номера). Например, разные цены или график для Казахстана.

Все диалоги всех номеров видны в одном списке, у каждого чата метка номера. Риск блокировки считается для каждого номера отдельно: если один номер заблокируют, бот не будет переключаться на другие номера, а продолжит работать только с теми, что подключены.

Телефон должен оставаться с интернетом хотя бы раз в 14 дней, иначе связанное устройство отключится. Компьютер с ботом должен быть включён: пока он выключен или спит, бот не отвечает. Не открывайте WhatsApp Web этого номера в браузере одновременно с ботом.

## Что умеет

- Отвечает по базе знаний из папки `knowledge/` (обычные .md файлы, правки подхватываются без перезапуска).
- Общается от лица персоны (имя и тон задаются в `knowledge/01-persona.md`), без пометки «ИИ» в каждом сообщении.
- **Не отрицает, что он ИИ:** если клиент всерьёз спрашивает, бот честно говорит, что он виртуальный ассистент, и предлагает позвать специалиста. Это правило зашито в коде (`src/ai.js`) и требуется правилами WhatsApp и законами о раскрытии ИИ.
- Передаёт диалог человеку, если клиент просит, злится, вопрос про деньги или доступ к аккаунту, ответа нет в базе знаний или бот не справился.
- Ждёт несколько секунд после последнего сообщения клиента и отвечает на всё сразу (клиенты часто пишут тремя короткими сообщениями).
- Если оператор написал в чат, бот замолкает в этом чате (по умолчанию на 60 минут или пока оператор не нажмёт «Вернуть боту»).
- Повторные доставки вебхука не создают дублей ответов.

## Как устроено

```
Клиент → WhatsApp → партнёр (BSP) → POST /webhook → сервер → Claude
                                                       ↓
Клиент ← WhatsApp ← партнёр (BSP) ← API отправки ← ответ
                                                       ↓
                                        Панель оператора /admin
```

Данные хранятся в SQLite (`data/bot.db`), отдельная база не нужна.

## Запуск (официальный API)

Нужен Node.js 22.13 или новее.

```bash
npm install
cp .env.example .env     # заполните ключи
npm start
```

### Проверка без WhatsApp и без ключа ИИ

В `.env` поставьте `WA_DRY_RUN=true` и `AI_MOCK=true`, запустите `npm start`, затем в другом окне:

```bash
npm run simulate -- "Здравствуйте, не работает интернет"
```

Откройте `http://localhost:3000/admin` (логин `admin`, пароль из `ADMIN_PASSWORD`): там появится диалог. С настоящим `ANTHROPIC_API_KEY` и `AI_MOCK=false` ответы будет писать Claude.

## Публичный адрес через ngrok (только для официального API)

ngrok открывает доступ к серверу на вашем компьютере по HTTPS-адресу, который можно указать партнёру как вебхук.

1. Зарегистрируйтесь на ngrok.com и скопируйте токен: https://dashboard.ngrok.com/get-started/your-authtoken
2. В разделе Domains получите бесплатный постоянный домен (вида `abc-xyz.ngrok-free.app`). Без него адрес меняется при каждом перезапуске, и вебхук у партнёра придётся менять каждый раз.
3. В `.env` заполните:
   ```
   NGROK_AUTHTOKEN=ваш-токен
   NGROK_DOMAIN=abc-xyz.ngrok-free.app
   ```
4. Задайте надёжный `ADMIN_PASSWORD`: панель оператора будет доступна из интернета.
5. Запустите `npm start`. В консоли появится строка `Адрес вебхука для кабинета партнёра: https://abc-xyz.ngrok-free.app/webhook`. Её и укажите у партнёра. Панель оператора будет доступна по `https://abc-xyz.ngrok-free.app/admin`.

ngrok встроен в сервер (пакет `@ngrok/ngrok`), отдельную программу ставить не нужно. Если `NGROK_AUTHTOKEN` пуст, ngrok не запускается.

Учтите: бот работает, только пока включён компьютер с сервером. Если компьютер выключится или уснёт, клиенты останутся без ответа. Для круглосуточной работы позже можно перенести тот же код на VPS, ничего не меняя.

## Подключение WhatsApp через партнёра

1. Выберите **официального партнёра Meta** (BSP), который работает с компаниями из России или Казахстана. Убедитесь, что это именно WhatsApp Business API, а не подключение «по QR-коду» (это неофициальный WhatsApp Web, номер банят).
2. Партнёр поможет создать Meta Business, пройти верификацию и подключить номер. Номер, подключённый к API, нельзя одновременно использовать в обычном приложении WhatsApp.
3. Дайте серверу публичный HTTPS-адрес. Проще всего через ngrok (см. ниже), без своего домена и VPS.
4. В кабинете партнёра укажите адрес вебхука: `https://ваш-домен/webhook` (при запуске с ngrok сервер сам напечатает готовый адрес).
5. В `.env` укажите провайдера:
   - **360dialog:** `WA_PROVIDER=360dialog`, `D360_API_KEY=...`
   - **Напрямую Meta:** `WA_PROVIDER=meta`, `META_ACCESS_TOKEN`, `META_PHONE_NUMBER_ID`, `META_APP_SECRET`
   - **Другой партнёр с API в формате Cloud API:** `WA_PROVIDER=custom`, `CUSTOM_SEND_URL`, `CUSTOM_AUTH_HEADER`, `CUSTOM_AUTH_VALUE`

   Если партнёр не подписывает вебхуки, задайте `WEBHOOK_KEY` и укажите адрес как `https://ваш-домен/webhook?key=...`.

Если у выбранного партнёра свой формат API (не Cloud API), нужен небольшой адаптер в `src/whatsapp.js`: функции `sendText` и `parseWebhook`.

## Важно про правила WhatsApp

- **Окно 24 часа.** Свободным текстом можно отвечать только в течение 24 часов после последнего сообщения клиента. Ответы в этом окне бесплатны. Писать первым или позже можно только одобренными шаблонами (в этом боте не используется).
- Бот должен заниматься делами вашего бизнеса, а не быть универсальным чат-ботом.
- Рассылки и массовые сообщения тем, кто вам не писал, запрещены.

## Нагрузочный тест ИИ

Проверяет, как выбранный ИИ справляется, когда пишут несколько клиентов одновременно. Клиентов тоже играет ИИ (тот же, что выбран в панели): у каждого своя ситуация (не работает интернет, хочет компенсацию, спрашивает «вы человек?», пишет по-казахски и т.д.). **В WhatsApp ничего не отправляется**: сообщения идут прямо на ваш сервер, ответы бота только пишутся в лог.

1. Запустите сервер в тестовом режиме:
   ```bash
   WA_DRY_RUN=true npm start
   ```
   (в Windows: поставьте `WA_DRY_RUN=true` в `.env` и запустите `npm start`). Без этого тест не запустится.
2. В другом окне:
   ```bash
   npm run loadtest -- --customers 5 --rate 20 --minutes 3
   ```
   - `--customers` — сколько клиентов пишут одновременно;
   - `--rate` — сколько всего сообщений клиентов в минуту;
   - `--minutes` — длительность.
3. Смотрите диалоги в панели оператора, а в конце теста будет отчёт: время ответа бота (среднее, медиана, 95%, максимум), сколько диалогов передано оператору, ошибки, сколько раз ИИ ответил «слишком много запросов» (429) и сколько токенов ушло на один ответ.

Тестовые чаты идут от номера «loadtest» и не расходуют дневной лимит ваших настоящих номеров. Учтите, что тест тратит запросы к ИИ (и бота, и «клиентов»): на бесплатных тарифах он может съесть дневной лимит. Для теста без ИИ поставьте `AI_MOCK=true`.

На что смотреть: если 95% ответов дольше 30–60 секунд или много ошибок 429, выбранный ИИ не тянет нагрузку. Тогда уменьшите число клиентов, выберите другую модель или сервис. Для 100 ответов в день хватает примерно 1–2 сообщений в минуту в пике.

## Какой ИИ выбрать

В панели оператора можно выбрать Claude или любой сервис с API в формате OpenAI. Правила поведения бота (тема только ваш бизнес, честный ответ на вопрос «вы бот?», передача оператору) одинаковые для всех.

| Вариант | Цена | Из России | Комментарий |
|---|---|---|---|
| **Ollama на вашем компьютере** | бесплатно, без лимитов | работает | Рекомендую как бесплатный вариант. Переписка клиентов никуда не уходит. Нужен компьютер с 16 ГБ памяти или больше (лучше с видеокартой). Установка: ollama.com, затем `ollama pull qwen3:8b`. На слабом компьютере ответ может идти десятки секунд. |
| Google Gemini | бесплатный тариф с дневным лимитом | не работает с российских IP | Из Казахстана работает. На бесплатном тарифе Google может использовать переписку для обучения моделей. Ключ: aistudio.google.com |
| Groq | бесплатный тариф с дневным лимитом | проверьте сами | Быстрый. Ключ: console.groq.com |
| OpenRouter | бесплатные модели (с `:free`) | обычно работает | Без пополнения счёта у бесплатных моделей маленький дневной лимит запросов, может не хватить на 100 ответов. Ключ: openrouter.ai/keys |
| Claude (Anthropic) | платно, по токенам | оплата российскими картами не проходит | Лучше всех следует правилам и пишет по-русски. Ключ: console.anthropic.com |

Лимиты бесплатных тарифов и доступность по странам часто меняются, перед запуском проверьте актуальные условия на сайте сервиса. Бесплатные модели слабее: чаще ошибаются и хуже держат формат ответа. Если модель вернула ответ не в том формате, бот всё равно отправит текст, но может не передать диалог оператору, когда нужно. Поэтому первые дни смотрите диалоги в панели.

Ollama и бот должны работать на одном компьютере: адрес по умолчанию `http://localhost:11434/v1`.

## Стоимость ИИ (Claude)

По умолчанию стоит `AI_MODEL=claude-opus-5-5` с `AI_EFFORT=low` (быстрые короткие ответы). Цена зависит от длины базы знаний и диалогов; базу знаний кэширует API, поэтому повторные запросы дешевле. Для экономии можно поставить `AI_MODEL=claude-haiku-5-5`, но качество ответов в сложных случаях будет ниже. Перед запуском на всех клиентах проверьте на тестовых диалогах.
